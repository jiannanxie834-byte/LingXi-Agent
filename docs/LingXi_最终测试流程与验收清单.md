## 三、对话与路由测试

| 输入 | 期望 |
|---|---|
| 我要学习 CNN | 命中深度学习课程图谱，返回学习建议，可生成路线和资源 |
| LSTM 是什么 | 只做概念解释，不强制生成全部资源 |
| 帮我规划 Transformer 学习路线 | 生成学习路线和配套 Artifact |
| 给我一个 PyTorch 图像分类实验 | 生成 PyTorch 实操案例方向 |
| 好 | 普通确认，不生成学习路线，不生成资源 |
| 不聊 CNN | 清空当前主题并询问新的深度学习方向 |
| 聊点别的吧 | 不继续旧主题，不生成资源 |
| 我要学习信息安全 | 提示当前主线聚焦《深度学习》，不生成资源 |
| 我要学习法语 | 提示课程外主题，不生成资源 |

学生端不得出现 Agent 原始输出、知识库全文、推荐分数、命中标签、调试 JSON 或推理过程。

## 十、深度学习课程化专项验收

| 测试项 | 方法 | 期望 |
|---|---|---|
| 课程图谱 | 访问 `/api/course/deep-learning/map` | 返回 12 个章节和 12 个知识单元 |
| 语义接地 | 发送 `我要学习 CNN`、`我不懂反向传播`、`帮我学 Transformer` | 分别命中 CNN、反向传播、Transformer 相关 unit_id |
| 资源生成任务 | 发送 `帮我生成 CNN 的个性化学习资源包，我偏好图解和代码` | 聊天先返回，后台生成 GenerationJob 和 Artifact |
| Artifact 类型 | 查看 `/api/resource/artifacts` 或资源工厂 | 出现课程讲解、导图、练习、阅读、PyTorch、PPT、视频、观看指南、交互动画、动画分镜、项目任务 |
| PPTX 导出 | 点击 PPT 大纲资源的导出按钮，或访问 `/api/resource/artifacts/{artifact_id}/export/pptx` | 下载 `.pptx` 文件 |
| 视频资源合规 | 打开外部公开视频推荐卡 | 只展示原始链接、片段建议和版权提示，不下载、不搬运、不重托管 |
| 交互动画 | 打开 CNN、反向传播或 Attention 动画规格资源 | 前端渲染对应动画组件或分镜说明 |
| 诊断报告门禁 | 普通 `我要学习 CNN` 请求 | 不生成“诊断与补弱报告” |
| 真实反馈诊断 | 输入 `我做 CNN 练习题时总是算错输出特征图尺寸` | 可生成补弱类资源并更新弱点、易错模式 |
