# LingXi 最终使用教程

## 一、系统简介

灵析学伴是面向高校《深度学习》课程的个性化多模态资源生成与学习多智能体系统。系统支持学生通过自然语言提出学习需求，由多个智能体协同完成意图识别、画像更新、课程图谱匹配、知识检索、学习辅导、路径规划、Artifact 资源生成、教师审核和学习效果评估。

## 四、学生端流程

### 1. 登录

打开网站后进入登录页。学生登录后进入首页对话。

### 2. 首页对话

推荐输入：

```text
我要学习 CNN，并做一个图像分类小项目
```

或：

```text
帮我规划 Transformer 学习路线
```

系统会：

1. 判断是否属于《深度学习》课程范围。
2. 更新动态学习画像。
3. 返回学生可读的学习建议。
4. 生成学习路线。
5. 规划配套 Artifact 并进入审核流程。

弱语义输入示例：

```text
好
不聊 CNN
聊点别的吧
```

这些输入只会得到自然承接或追问，不会生成新路线和资源。

### 3. 资源工厂

进入“资源”页面查看已审核通过的深度学习 Artifact。支持按类型筛选和搜索。

资源类型包括课程讲解文档、思维导图、练习题集、阅读包、PyTorch 实操、PPT 大纲、公开视频推荐、观看指南、动画规格、动画分镜和课程项目任务书。

### 4. 规划页

进入“规划”页面查看自动生成的个性化学习路线。可以勾选任务完成、删除路线或新增自定义任务。

### 5. 评价页

进入“评价”页面进行学习效果评估。系统会根据平台数据、作答情况和补充错题生成评价结果，并在有真实反馈上下文时生成诊断与补弱报告。

### 6. 我的

进入“我的”页面查看动态学习画像、知识标签、学习时长和个人资料。

## 五、管理员端流程

### 1. 控制台

管理员登录后进入控制台，查看待处理事项、资源数量、学生数量和反馈状态。

### 2. 资源审核

进入“资源工厂审核与管理”，查看未处理、已通过、未通过资源。管理员可以查看详情、通过、下架、重新上线或提出修改意见。

### 3. 分类审核

学生申请自定义 Tab 分类后，管理员可在分类审核区处理。处理后学生端会收到系统消息。

### 4. 学生管理

查看学生账号、昵称、角色、学习画像摘要和学习状态。

### 5. 反馈中心

处理学生反馈，支持查看、标记和删除。

## 六、课程外主题处理

如果学生输入：

```text
我要学习信息安全
```

或：

```text
我要学习法语
```

系统会提示当前主线聚焦《深度学习》，不会套用深度学习资源模板，也不会生成路径和资源。

## 七、演示建议

7 分钟演示可以按以下顺序：

1. 登录页和产品定位。
2. 学生输入 CNN 学习需求。
3. 展示对话回复、画像更新、规划页路线。
4. 管理员审核 Artifact。
5. 学生收到消息并进入资源工厂查看。
6. 学生完成学习评价。
7. 管理端查看诊断与补弱报告审核。
