# LingXi 演示基准数据说明

## 数据策略

当前正式演示库使用 MySQL。旧 SQLite 文件 `lingxi.db` 只作为早期本地测试文件，不作为演示底库，不建议提交。

演示数据以《深度学习》课程为主线，覆盖学生、管理员、课程知识库、已审核资源、待审核资源、学习规划、学习评价、系统消息和聊天历史。

## 推荐演示数据路径

1. 学生登录。
2. 首页输入“我要学习 CNN，并做一个图像分类小项目”。
3. 系统返回学习建议，生成学习路线，并提示配套 Artifact 进入审核。
4. 管理员登录，进入资源工厂审核。
5. 查看待审核资源，确认包含课程讲解、练习题、PyTorch 实操、视频推荐、动画规格或项目任务。
6. 管理员通过资源。
7. 学生右上角消息收到审核通知。
8. 学生进入资源工厂查看审核通过的资源。
9. 学生进入评价页完成学习评价。
10. 系统基于真实评价生成诊断与补弱报告。

## 演示重点

- 对话式学习画像自主构建。
- Conversation Router 避免“好”“换个话题”等弱语义输入误触发完整链路。
- 深度学习课程图谱命中后才生成学习路线和资源。
- 课程外主题不套模板，不生成错配资源。
- Artifact 资源先进入教师审核，再进入学生资源工厂。
- 诊断与补弱报告必须有评价、错题或测验上下文。
