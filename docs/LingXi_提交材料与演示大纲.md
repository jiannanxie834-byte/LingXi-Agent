# LingXi 提交材料与演示大纲

## 一、提交材料清单

1. 演示 PPT。
2. 可完整运行的前后端源码。
3. 《深度学习》课程知识库与数据集。
4. 模型调用配置示例，不包含真实 Key。
5. 系统开发说明书、测试说明书、赛题匹配度报告。
6. 7 分钟以内智能体演示视频。
7. AI Coding 工具使用说明。

## 二、PPT 大纲

1. 项目名称：灵析学伴 · 面向《深度学习》课程的个性化多模态资源生成与学习多智能体系统。
2. 高校学生痛点：资源分散、路线不清、反馈滞后、内容质量不可控。
3. 系统目标：对话画像、课程图谱、个性化路径、Artifact 资源工厂、教师审核、学习评价闭环。
4. 总体架构：前端 Vue、后端 FastAPI、MySQL、LLM Provider、多智能体编排、课程知识库。
5. 《深度学习》课程知识库：12 章、12 知识单元、公开视频目录、PyTorch 实验。
6. 多智能体协作：意图、语义接地、画像、检索、规划、资源设计、教学资料筛选、安全门禁。
7. 资源 Artifact 体系：讲解、导图、练习、阅读、代码、PPT、视频、观看指南、动画、项目、诊断报告。
8. 个性化学习路径与精准推送。
9. 教师审核与内容安全。
10. 学习评价与补弱优化。
11. 创新点与实用价值。
12. 演示流程和总结。

## 三、7 分钟演示视频脚本

| 时间 | 内容 |
|---|---|
| 0:00-0:30 | 展示项目定位和登录页 |
| 0:30-1:30 | 学生输入“我要学习 CNN，并做一个图像分类小项目” |
| 1:30-2:10 | 展示学生端回答、画像更新和学习路线 |
| 2:10-3:00 | 管理员进入资源审核，查看 Artifact 详情并通过 |
| 3:00-3:40 | 学生收到系统消息，进入资源工厂查看资源 |
| 3:40-4:40 | 展示 PyTorch 实操、视频推荐、动画规格或项目任务 |
| 4:40-5:40 | 学生进入评价页，提交学习反馈或错题说明 |
| 5:40-6:30 | 管理员查看诊断与补弱报告 |
| 6:30-7:00 | 总结赛题匹配和创新点 |

## 五、AI Coding 工具说明

项目开发过程中使用了 AI Coding 工具辅助完成代码阅读、接口补齐、前后端调试、测试文档生成和界面优化。所有生成内容均由开发者在本地运行、检查和修正后纳入项目。

## 六、开源工具说明

- Vue 3：前端框架。
- Vite：前端构建工具。
- Pinia：前端状态管理。
- Element Plus：组件库。
- FastAPI：后端 Web 框架。
- SQLAlchemy：ORM。
- MySQL：正式演示数据库。
- ECharts：画像和统计图表。
- Mermaid、KaTeX、Markdown 渲染：学习资源展示增强。
