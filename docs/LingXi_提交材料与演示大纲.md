## 2. 演示 PPT 大纲

赛题要求：

> 演示 PPT 须清晰展示智能体应用价值、前沿 AI 技术融合思路与实现方法、创新价值、核心功能等内容，逻辑清晰、重点突出。

建议 14 页左右。

### 第 1 页：封面

标题：

```text
LingXi 灵析学伴
面向高等教育的多智能体个性化学习资源生成系统
```

内容：

- 团队名称
- 成员
- 赛题名称
- 日期

视觉建议：

- 使用系统首页或资源库截图作为背景。
- 不要用纯文字封面。

### 第 2 页：问题背景

讲清痛点：

- 高校学习资源繁杂。
- 学生基础、目标、节奏差异明显。
- 传统课程资源难以做到因材施教。
- 普通 AI 问答缺少课程依据和学习闭环。

结论：

```text
学生需要的不只是答案，而是可信依据、个性化资源和持续学习路径。
```

### 第 3 页：系统目标

展示系统目标：

1. 对话式构建学生画像。
2. 基于课程知识库提供可信回答。
3. 多智能体生成个性化学习资源。
4. 动态规划学习路线。
5. 通过评价诊断持续优化。
6. 管理员审核保证内容质量。

### 第 4 页：整体业务闭环

建议放流程图：

```text
学生对话
-> 意图识别
-> 知识库依据检索
-> 学习画像更新
-> 个性化辅导
-> 路径规划
-> 资源生成
-> 内容安全自检
-> 管理员审核
-> 资源发布
-> 学习评价
-> 画像与路径更新
```

重点讲：

- 系统不是单点功能，而是完整闭环。

| 学习辅导 Agent | 生成个性化解释 |
| 路径规划 Agent | 规划学习步骤 |
| 资源设计 Agent | 生成多类型资源 |
| 内容安全 Agent | 防幻觉与安全自检 |
| 评价诊断 Agent | 分析学习效果 |

## 4. 智能体演示视频大纲

赛题要求：

> 时长控制在 7 分钟之内，清晰展示系统操作流程、核心功能、多模态资源生成效果及前沿 AI 技术应用成果。

建议视频总时长：6 分 40 秒左右，留 20 秒余量。

### 0:00-0:25 开场

画面：

- PPT 封面或系统登录页。

讲解：

```text
我们作品是 LingXi 灵析学伴，一个面向高等教育的多智能体个性化学习资源生成系统。
系统以《人工智能导论》课程知识库为基础，通过对话构建学生画像，生成可信资源和学习路径。
```

### 0:25-0:55 登录与系统概览

画面：

- 学生登录。
- 首页对话界面。

讲解：

- 未登录先进入登录页。
- 学生登录后进入 AI 学习助手。

### 0:55-1:55 知识库依据链问答

操作：

输入：

```text
请根据课程知识库解释监督学习和混淆矩阵的关系。
```

展示：

- 多智能体处理链路。
- 知识库依据。
- AI 回复。

讲解：

```text
系统不是直接让大模型自由发挥，而是先检索课程知识库和已审核资源，再组织回答。
```

### 1:55-2:55 路径规划与资源生成

操作：

输入：

```text
我想系统学习人工智能导论中的监督学习，请帮我规划路线并生成配套资源。
```

展示：

- 意图识别。
- 画像更新。
- 路径规划。
- 资源生成。
- 内容安全自检。

讲解：

- 多智能体协同。
- 生成资源先进入管理员审核。

### 2:55-3:45 资源库与多模态学习包

操作：

- 进入资源库。
- 搜索 `监督学习` 或 `多模态`。
- 打开资源详情。

展示：

- Markdown 正文。
- Mermaid 流程图。
- 代码注释。
- 分步题解。
- PPT 页纲。
- 导出 PPT。

讲解：

```text
多模态不只等于视频，系统把同一知识点拆成文字、图示、代码、题解、课件和实践任务等多种表达方式。
```

### 3:45-4:30 学习规划页

操作：

- 进入规划页。
- 展示 AI 路线。
- 修改任务状态。
- 新增待办。

讲解：

- 路线可持久保存。
- 学生可参与调整。
- 执行情况反向影响画像。

### 4:30-5:15 学习评价与错题诊断

操作：

- 进入评价页。
- 点击自动诊断。
- 补充错题说明。

展示：

- 诊断报告。
- 薄弱点。
- 补救建议。

讲解：

- 学习后评估。
- 评价结果持续优化画像和路线。

### 5:15-6:15 管理员审核治理

操作：

- 登录 admin。
- 进入控制台。
- 展示演示就绪检查。
- 进入资源审核。
- 查看内容安全自检。
- 审核资源。
- 处理反馈。

讲解：

```text
生成式内容不能直接进入教学资源库，系统通过内容安全 Agent 和管理员审核形成质量治理闭环。
```

### 6:15-6:40 总结

画面：

- 回到 PPT 或管理员控制台。

讲解：

```text
LingXi 灵析学伴完成了对话画像、知识库依据、多智能体资源生成、路径规划、学习评价和审核治理闭环，满足赛题对高等教育个性化、多模态学习资源智能体系统的要求。
```
