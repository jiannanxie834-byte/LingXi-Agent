# LingXi 初始课程知识库说明

## 1. 建设目的

软件杯赛题要求参赛团队自行构造至少一门完整高校专业课程的初始知识库/文档集作为系统输入。当前项目已构建《人工智能导论》课程知识库，并接入后端初始化流程。

该知识库不是单独摆放的说明材料，而是会在后端启动时写入数据库：

- `course_knowledge`：用于评价诊断、知识点识别、补弱路线。
- `resources`：用于学生端资源库展示和管理员端资源治理。
- `chat_messages.metadata_json`：用于保存每次对话命中的知识库依据、处理链路和安全摘要，刷新后仍可回看。

## 4. 覆盖范围

知识库覆盖 8 个核心知识点：

1. 人工智能概述
2. 搜索与问题求解
3. 机器学习基础
4. 监督学习与模型评估
5. 神经网络与深度学习
6. 自然语言处理与大语言模型
7. 多模态学习资源生成
8. AI 安全、伦理与防幻觉

系统会同步 12 份初始资源到资源库，包括课程大纲、章节讲义、练习题库、实践项目和学习路径模板。

## 5. 演示方式

1. 启动后端，观察终端输出：`初始课程知识库已同步`。
2. 登录学生端，进入资源库。
3. 查看《人工智能导论》相关资源。
4. 打开“第 7 章 多模态资源生成与智能体协同”，展示 Mermaid 流程图、多模态资源表和实践任务。
5. 点击资源详情里的“导出PPT”，展示系统可以把知识库资源转换为真实课件。
6. 在对话页输入：“我监督学习的混淆矩阵总是分不清，请帮我规划复习路线。”
7. 展示系统先命中“监督学习与模型评估”等课程依据，再完成答疑、画像更新、路径规划和资源生成。
8. 刷新页面或切换会话，确认历史消息仍保留“多智能体处理链路”和“知识库依据”。

## 6. 赛题对应说明

该知识库对应赛题要求中的：

- 自行构造至少一门完整高校专业课程的初始知识库/文档集。
- 支持个性化资源生成。
- 支持多模态学习资源。
- 支持个性化学习路径规划。
- 支持学习效果评估和错题诊断。
- 支持内容安全与防幻觉审核。
- 支持知识库证据链，降低生成式回答的幻觉风险。
